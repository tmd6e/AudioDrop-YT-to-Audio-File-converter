AUDIODROP

Double-click Launch AudioDrop.bat. Paste a YouTube video URL, select an
audio format, browse to your destination folder, and click Download audio.
The default destination is Downloads\AudioDrop in your user folder.
Your folder and format are remembered. Playlist links download one video.

Formats: MP3, WAV, FLAC, M4A, AAC, OGG (Vorbis), Opus, and ALAC (in M4A).
Lossless output does not improve the quality of the original YouTube audio.

Requires Python 3.10+, FFmpeg/ffprobe and Node.js on PATH, and internet access.
The bundled local Python environment contains yt-dlp and its dependencies.
If YouTube changes break downloads, run Update downloader.bat.
Some private, age-restricted, or blocked videos cannot be downloaded.

Downloader documentation: https://github.com/yt-dlp/yt-dlp
See README.md for GitHub publishing and executable build instructions.
