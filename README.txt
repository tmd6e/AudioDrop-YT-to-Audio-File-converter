AUDIODROP

Recommended: download AudioDrop-Setup from the GitHub Releases page and run it.
Portable: extract the complete ZIP, open AudioDrop, and run AudioDrop.exe.
Python, FFmpeg, and Node.js are included. No extra installation is needed.

Paste a YouTube URL or click Search YouTube, select a format and destination,
optionally enter a filename, and click Download audio.

See README.md for illustrated-by-steps installation and usage instructions.
https://github.com/tmd6e/AudioDrop-YT-to-Audio-File-converter/releases/latest
